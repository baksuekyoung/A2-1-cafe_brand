# 단계 간 데이터 계약

> 1~4단계가 **무슨 형식으로** 결과를 넘길지 정한 문서입니다.
> 5단계(결과 저장·에러 처리 통합)를 맡은 노희선이 작성했습니다.

---

## 왜 이 문서가 먼저 나왔나

박연수님이 이렇게 적으셨습니다.

> "이전 텀프로때 제가 최종 MD파일 작성을 맡았었는데 ... **설계한 분의 작업물이랑 맞지가 않다보니 파일 정리에 좀 시간이 걸렸어서**"

이건 사람 문제가 아니라 **순서 문제**입니다. 각자 코드를 먼저 쓰고 마지막에 합치면,
합치는 사람이 남의 코드 다섯 개를 읽어서 형식을 맞춰야 합니다.

그래서 **코딩을 시작하기 전에** 넘길 형식만 먼저 정합니다.
이 문서의 형식대로만 돌려주시면, 통합은 제가 합니다. 서로의 코드를 읽을 필요가 없습니다.

**형식만 지키면 내부 구현은 자유입니다.** 어떤 라이브러리를 쓰든, 함수를 몇 개로 쪼개든 상관없습니다.

---

## 전체 흐름

```
[1] 브랜드 브리프        →  brief      (dict)
[2] 네이밍·슬로건·스토리  →  naming     (dict)
[3] 컬러 팔레트          →  palette    (dict)
[4] 로고 시안            →  logos      (list)
                              ↓
[5] 결과 저장 & 에러 처리 통합
     brand_result.json / brand_result.md / brand_tokens.css / logo_01.png / run_report.md
```

---

## [1] 브랜드 브리프 — `brief`

담당: 미정

```python
{
  "brand_name_hint": "쉼표",          # 원하는 이름 힌트 (없으면 "")
  "industry": "카페",                  # 업종
  "target": "20-30대 직장인",          # 타깃
  "keywords": ["휴식", "단정함"],       # 키워드 2개 이상
  "tone": "차분하고 간결한",            # 톤앤매너
  "extra": ""                          # 자유 메모 (없으면 "")
}
```

| 키 | 타입 | 필수 | 비고 |
| --- | --- | :---: | --- |
| `brand_name_hint` | str | ✅ | 빈 문자열 허용 |
| `industry` | str | ✅ | |
| `target` | str | ✅ | |
| `keywords` | list[str] | ✅ | **2개 이상** |
| `tone` | str | ✅ | |
| `extra` | str | ✅ | 빈 문자열 허용 |

**필수 키가 없으면 5단계에서 에러로 잡아 `run_report.md` 에 남깁니다.** 값이 비어 있는 건 괜찮지만, 키 자체는 있어야 합니다.

---

## [2] 네이밍 · 슬로건 · 스토리 — `naming`

담당: 박연수, 박수경

```python
{
  "names": [
    {"name": "쉼표", "reason": "문장을 잠시 멈추는 기호에서 따왔습니다"},
    {"name": "여백",  "reason": "비어 있음이 곧 쉼이라는 뜻입니다"},
    {"name": "한숨",  "reason": "크게 내쉬는 숨을 뜻합니다"}
  ],
  "slogan": "잠깐 멈추셔도 됩니다",
  "story": "하루에 한 번은 쉼표가 필요합니다. ..."   # 200자 이상
}
```

| 키 | 타입 | 필수 | 비고 |
| --- | --- | :---: | --- |
| `names` | list[dict] | ✅ | **3개 이상**, 각 항목에 `name`·`reason` |
| `slogan` | str | ✅ | |
| `story` | str | ✅ | **200자 이상** |

> **`names[0]` 이 대표 이름으로 쓰입니다.** 가장 좋은 안을 맨 앞에 놓아 주세요.

---

## [3] 컬러 팔레트 — `palette`

담당: 박연수, 박수경

```python
{
  "main": {"hex": "#2F4858", "name": "딥 네이비", "reason": "차분함을 위해 채도를 낮췄습니다"},
  "subs": [
    {"hex": "#F6F4F1", "name": "웜 화이트", "reason": "여백을 만듭니다"},
    {"hex": "#C9A227", "name": "머스터드",   "reason": "포인트 색입니다"}
  ]
}
```

| 키 | 타입 | 필수 | 비고 |
| --- | --- | :---: | --- |
| `main` | dict | ✅ | `hex`·`name`·`reason` |
| `subs` | list[dict] | ✅ | **2개 이상**, 같은 구조 |

### HEX 형식을 지켜 주세요

`#` 을 붙인 **6자리 대문자**로 주세요 — `#2F4858` ⭕ / `2f4858` ❌ / `rgb(47,72,88)` ❌

5단계가 이 값으로 **명도 대비를 계산**하고 CSS 변수를 만듭니다. 형식이 다르면 계산이 안 됩니다.
(대비가 4.5:1 미만이면 저장은 하되 `run_report.md` 에 경고를 남깁니다. 웹 접근성 기준입니다.)

## [4] 로고 시안 — `logos`

담당: 이예은

```python
[
  {"image_bytes": b"\x89PNG...", "prompt": "A minimal comma-shaped logo mark, ..."},
  {"image_bytes": b"\x89PNG...", "prompt": "..."}
]
```

| 키 | 타입 | 필수 | 비고 |
| --- | --- | :---: | --- |
| `image_bytes` | bytes | ✅ | PNG **원본 바이트** |
| `prompt` | str | ✅ | 이미지 생성에 쓴 영어 프롬프트 |

`image_bytes` 대신 **이미 저장한 파일 경로**를 주셔도 됩니다.

```python
[{"path": "output/logo_raw_01.png", "prompt": "..."}]
```

둘 중 하나만 있으면 됩니다. `image_bytes` 가 있으면 그걸 먼저 씁니다.

> **프롬프트는 한국어를 영어로 옮겨서 넣어 주세요.** 한국어 주제를 이미지 API 에 그대로 넘기면
> 엉뚱한 그림이 나옵니다 (이전 과제에서 "20-30대 여성"을 인물 사진 요청으로 읽어 사람 사진이 나왔습니다).
> 그 영어 프롬프트를 `prompt` 에 그대로 담아 주시면 결과 문서에 근거로 남습니다.

## [5] 결과 저장 & 에러 처리 통합

담당: **노희선**

위 네 가지를 받아 아래를 만듭니다.

| 파일 | 내용 |
| --- | --- |
| `brand_result.json` | 텍스트 결과 전체 |
| `brand_result.md` | **사람이 읽는 결과 문서** |
| `brand_tokens.css` | 팔레트를 CSS 변수·Tailwind 설정으로 |
| `logo_01.png` … | 로고 시안 |
| `run_report.md` | 어느 단계가 성공/실패했는지 |

### `brand_result.md` 가 제일 중요합니다

> **평가는 코드와 마크다운(.md) 문서만 봅니다.**

JSON 만 남기면 평가자가 결과를 볼 방법이 없습니다. 터미널 출력도 마찬가지입니다.
**반드시 `.md` 로 남겨서 커밋해야 합니다.**

---

## 한 단계가 실패해도 멈추지 않습니다

5단계는 **부분 실패를 허용**합니다.

- 2단계가 실패해도 3·4단계 결과는 저장됩니다
- 이미지 API 가 막혀도 텍스트 결과는 남습니다
- 무엇이 왜 실패했는지는 `run_report.md` 에 적힙니다

그래서 **각자 파트가 아직 안 끝나도 통합을 돌려볼 수 있습니다.** 빈 자리는 빈 자리로 표시됩니다.
막판에 한 번에 합치지 말고, 되는 데까지 자주 돌려 보세요.

## 넘겨주실 때

각 단계는 아래 형태의 **함수 하나**로 만들어 주세요.

```python
# step2_naming.py
def generate_naming(brief: dict) -> dict:
    """위 [2] 규격의 dict 를 돌려준다."""
    ...
```

| 단계 | 파일명 | 함수명 |
| --- | --- | --- |
| [1] | `step1_brief.py` | `load_brief() -> dict` |
| [2] | `step2_naming.py` | `generate_naming(brief) -> dict` |
| [3] | `step3_palette.py` | `generate_palette(brief, naming) -> dict` |
| [4] | `step4_logo.py` | `generate_logos(brief, naming, palette) -> list` |

이 이름만 맞춰 주시면 제가 그대로 불러다 씁니다. **파일 하나, 함수 하나면 됩니다.**
