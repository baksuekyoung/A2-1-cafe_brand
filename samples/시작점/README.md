# 시작점 — 각자 파트를 여기서부터

> **완성품이 아닙니다.** 형식만 맞춰 둔 **빈 껍데기**입니다.
> AI 호출은 여러분이 채우셔야 합니다. 그 안쪽이 이 과제의 핵심이니까요.

---

## 무엇을 하면 되나

1. 자기 파트 파일을 **프로젝트 맨 위 폴더로 복사**합니다
2. 파일 안의 `# 👉 여기를 채웁니다` 부분에 AI 호출을 넣습니다
3. `python integrate.py` 를 돌려 ⬜ 가 ✅ 로 바뀌는지 봅니다

```
samples/시작점/step2_naming.py  →  step2_naming.py   (맨 위 폴더로)
```

---

## 왜 이걸 만들어 뒀나

계약 문서에 형식을 글로 적어 뒀지만, **글만 보고 파일을 처음부터 만드는 건 부담**입니다.
빈 화면에서 시작하지 않아도 되게 껍데기만 두었습니다.

그리고 **네 파일을 전부 복사해 넣고 한 번 돌려 보면** 전체가 어떻게 이어지는지
눈으로 볼 수 있습니다. 가이드 체크리스트에 이런 항목이 있습니다.

> ✓ 4명 모두 **전체 파이프라인 흐름을 설명할 수 있는가**

한 번 돌려 보는 것이 설명을 열 번 읽는 것보다 빠릅니다.

---

## 지금 그대로 넣으면 어떻게 되나

고정된 예시 값이 들어 있어서 **4/4 로 통과합니다.**
결과 문서도, CSS 토큰도, 로고 파일도 다 나옵니다.

다만 그 내용이 진짜 AI 결과가 아니라 미리 적어 둔 글자입니다.
**그 자리를 진짜 AI 호출로 바꾸는 것이 각자의 과제입니다.**

> ⚠️ 예시 값을 그대로 두고 제출하면 안 됩니다.
> 가이드가 *"결과가 너무 일반적이지 않고 구체적인가"* 를 점검하라고 합니다.

### 규격은 진짜로 셉니다

만들면서 겪은 일입니다. 예시 스토리를 처음 썼을 때 **197자**였는데,
돌려 보니 이렇게 나왔습니다.

```
[2] 네이밍·슬로건·스토리 | ✅ 완료 | 규격 확인 필요 1건
  → [2] naming: story 가 197자입니다 (200자 이상 필요)
```

세 글자가 모자랐습니다. 눈으로는 절대 못 잡습니다.
**여러분 결과도 똑같이 셉니다.** 다만 버리지는 않고 `run_report.md` 에 적어 둡니다.
